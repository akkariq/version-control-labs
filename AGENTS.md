# СКВ · Как продолжать работу

Перед продолжением курса прочитать [docs/CONTEXT.md](docs/CONTEXT.md), актуальный README и соответствующую методичку. Затем проверить текущее состояние GitLab/GitHub: заметка содержит снимок, а не гарантию актуальности.

Не считать подготовленный файл опубликованным и не считать выполненную практику оценкой преподавателя. Сохранять оговорки, подтверждённые результаты и историю.

После завершения этапа предложить обновление docs/CONTEXT.md с точным следующим шагом. Любые записи через коннекторы публиковать только после требуемого подтверждения пользователя.

Этот файл — указатель для восстановления контекста, а не автоматическая память и не замена действующим инструкциям ассистента.
