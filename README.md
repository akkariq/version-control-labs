<details>
<summary>▸ Принципы публикации</summary>

Сначала проверяем практику по методичке, затем описываем фактические результаты, добавляем ответы и вывод, публикуем отчёт и обновляем контекст. Не скрываем отклонения от буквальных примеров. Не публикуем секреты и не подменяем отсутствие доказательств отметкой «выполнено». Word-версии обеих работ выданы отдельно; в репозитории пока размещены только Markdown-отчёты.

</details>
