<a id="workflow"></a>
## СКВ · Как устроен сборник

| GitLab — практика | GitHub — отчёты |
|---|---|
| Учебные проекты, коммиты и результаты операций | Паспорт, ход выполнения, проверка и выводы |
| Подтверждение истории изменений | Оглавление, раскрывающиеся блоки и вопросы для защиты |

```text
version-control-labs/
├── README.md                 # оглавление курса
├── assets/
│   └── course-cover.svg      # собственная векторная обложка
└── labs/
    └── lab01/
        └── README.md         # отчёт первой лабораторной
```

<details>
<summary>▸ Принципы оформления и публикации</summary>

1. Проверяем результаты по методичке.
2. Описываем фактические действия и их результаты.
3. Сохраняем ссылки на практический проект.
4. Добавляем ответы и заключение.
5. Публикуем работу и обновляем оглавление.

Неподтверждённые шаги и выдуманные скриншоты не включаются. Email автора не приводится в тексте публичного отчёта. Word-версия первой работы подготовлена отдельно, но в репозитории пока не размещена.

</details>
