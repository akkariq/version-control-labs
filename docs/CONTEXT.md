- Отчёты: Markdown и отдельный Word, паспорт таблицей, полные ФИО, заголовки с СКВ, три смысловые части, ответы и заключение.

- Каждая запись через коннектор — после требуемого подтверждения точного содержания. Подготовлено, опубликовано, проверено и оценено — разные статусы.
